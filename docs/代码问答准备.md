# 代码问答准备（自测清单）

> 用来自查「能不能讲清自己的代码」。老师抽查时会挑具体代码追问，下面每题都能用本项目代码回答。

## 一、算法

1. **EF 是什么？怎么更新？**
   `review_cards.easeFactor`，初始 2.5，按 SM-2：`EF' = EF + (0.1 - (5-q)*(0.08+(5-q)*0.02))`，夹在 `[1.3, 3.0]`。见 `EbbinghausScheduler.adjustEase`。

2. **为什么前两次间隔是 1 天、3 天？**
   这是学习步（learning steps），让新词在短期内连续出现两次再进入长间隔，避免一次答对就排到 6 天后。

3. **答错为什么是 10 分钟？**
   背单词需要当天内重复；10 分钟重学比隔天更符合实际。质量分 2（模糊偏下）走 30 分钟分支。

4. **记忆强度怎么算的？为什么这样设计？**
   `1 - exp(-interval/18)` 做间隔饱和，再叠加 EF 与连续答对次数；目的是给用户一个直观的 0~100% 进度，而不是只看天数。

## 二、Room 与数据

5. **为什么 `review_cards` 的 wordId 要加唯一索引？**
   一个单词只应有一张卡片，避免重复插入导致同一个词在队列里出现两次。

6. **删除词库会发生什么？**
   `words.bookId` 对 `word_books` 有外键，`ON DELETE CASCADE`；`review_cards` / `review_logs` / `wrong_records` 又对 `words.id` 级联。
   所以 `deleteBook` 只删 `word_books` 一行，单词、卡片、日志、错题都会被数据库连带清理，不会留下孤儿数据。

7. **Flow 查询和 suspend 查询怎么选？**
   需要跟着数据库变化自动刷新 UI → `Flow`（列表、数量）；一次性读取（如生成测试题、统计快照）→ `suspend`。

8. **`withTransaction` 用在哪两处？为什么？**
   `WordRepository.importBook`（词库+单词+卡片）与 `ReviewRepository.submitReview`（卡片+日志+错题）。中途失败必须整体回滚，否则统计与卡片状态不一致。

## 三、并发与生命周期

9. **为什么用 `repeatOnLifecycle(STARTED)` 而不是 `lifecycleScope.launch` 直接收？**
   前者在页面停止时自动取消收集，避免后台更新 UI 与内存泄漏。

10. **ViewModel 为什么不持有 Fragment/Context？**
    配置变更（旋转）时 ViewModel 存活，持有 View 会泄漏；需要 Context 的地方用 `applicationContext`（如 DataStore）。

11. **搜索为什么加 `debounce(250)`？**
    输入每个字符都触发数据库查询会造成抖动与浪费，250ms 内的连续输入只查最后一次。

## 四、权限与系统能力

12. **通知权限被拒绝后 App 怎么工作？**
    `NotificationHelper.canPost` 返回 false → Worker 不发通知 → 首页根据 `reminderEnabled && !canPost` 显示横幅。功能不崩溃。

13. **WorkManager 的初始延迟怎么算？**
    `ReminderScheduler.initialDelayMillis`：把 Calendar 设到今天的 hh:mm，若已过则加一天，返回差值。

14. **为什么用 `ExistingPeriodicWorkPolicy.UPDATE`？**
    用户修改提醒时间后，希望新时间立即生效；KEEP 会保留旧任务导致改时间无效。

15. **ContentProvider 的权限为什么是 signature？**
    只允许同一签名的 APK 读取；同一台机器 debug 构建共用 debug.keystore，所以两个 APK 装在一起就能互通，其他应用读不到。

## 五、伴生模块

16. **看板为什么不直接读主 App 数据库文件？**
    Android 每个应用有独立沙箱，数据库文件其他应用无权访问；Provider 是官方跨应用数据通道。

17. **图表是怎么画的？**
    自定义 View 重写 `onDraw`：柱状图按 `maxValue` 归一化计算每根柱子高度，再画圆角矩形；环形图用 `drawArc` 从 -90° 开始按百分比扫角度。

18. **CSV 导出怎么做到不要存储权限？**
    Android 10+ 用 `MediaStore.Downloads` 写入公共下载目录；Android 9 及以下写应用专属目录（`getExternalFilesDir`），两者都不需要权限。

## 六、工程

19. **三个模块怎么划分的？**
    `core` 无 UI 依赖（数据+算法），`app` 与 `dashboard` 是两个独立 APK；看板只依赖 `core` 的契约与数据模型。

20. **21 个单元测试覆盖了什么？**
    算法（8）、解析器（8）、连续打卡（5）。都在 JVM 上跑，不需要模拟器。
