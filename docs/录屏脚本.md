# 3 分钟录屏脚本

> **必须做**：录制前在 App 界面右上角叠加「学号 202405100117 · 王洲」水印（可用剪映文字贴纸，或提前在桌面放一张姓名条）。
> 录屏分两段：主 App 一段（约 3 分钟）、伴生模块一段（约 1.5~2 分钟）。全程不剪辑关键流程，保证「真实跑通」。

## 准备

1. 卸载重装两个 APK，保证数据干净（首次启动会导入内置词库）；
2. 关闭其他通知，避免干扰；
3. 手机/模拟器开启「显示点按操作」；
4. 提前准备一个测试词库文件 `demo_words.txt`（内容见文末）。

## 第一段：主 App（约 3 分钟）

| 时间 | 操作 | 讲解词（要点） |
| --- | --- | --- |
| 0:00-0:15 | 打开 App，进入首页 | 「这是单词记忆，核心是艾宾浩斯复习队列。首次启动自动导入了内置 CET-4 词库。」 |
| 0:15-0:35 | 指出顶部三个指标：今日已复习 / 连续打卡 / 已掌握 | 「这些数据来自 Room，界面用 StateFlow 自动刷新。」 |
| 0:35-1:30 | 点「开始复习」→ 点击卡片揭晓释义 → 依次点「忘记 / 模糊 / 记得 / 简单」 | 「四档评分对应 SM-2 的质量分 1/3/4/5。忘记会安排 10 分钟后重学，记得是 1 天，之后按 EF 增长。」 |
| 1:30-1:50 | 复习完成后回到首页，进入「词库 → 某个词库 → 某个单词详情」 | 「这里能看到复习间隔、EF、记忆强度和每一次复习记录。」 |
| 1:50-2:20 | 单词详情点「在线补充释义」 | 「免费词典 API，不需要 Key；断网时会提示网络不可用，本地功能不受影响。」 |
| 2:20-2:50 | 词库页 → 导入 → 选择 `demo_words.txt` → 预览 → 确认导入 | 「解析出 N 个词，跳过重复 M 个；词库、单词、复习卡片在一个事务里写入。」 |
| 2:50-3:10 | 首页「测试一下」→ 故意答错一题 → 打开「错题」 | 「答错自动进错题本，错误次数累加，可以单独再练。」 |
| 3:10-3:25 | 进入「我的」→ 打开提醒开关 → 拒绝通知权限 | 「拒绝后不会崩，提示已降级为应用内提醒，首页出现横幅。」 |

## 第二段：伴生模块（约 1.5 分钟）

| 时间 | 操作 | 讲解词 |
| --- | --- | --- |
| 0:00-0:20 | 从桌面单独启动「单词看板」 | 「这是独立 APK，可以单独启动，数据来自主 App 的 ContentProvider。」 |
| 0:20-0:50 | 展示总览卡片、14 天柱状图、正确率环形图、错词榜 | 「两个图表都是 Canvas 自绘，没有用第三方图表库。」 |
| 0:50-1:10 | 点「导出 CSV」，下拉通知栏/文件管理找到文件 | 「导出到下载/WordMemory，Android 10 以上不需要存储权限。」 |
| 1:10-1:20 | 回主 App 复习几个词，再切回看板点刷新 | 「数据实时打通，刷新后数字变化。」 |
| 1:20-1:30 | （可选）卸载主 App 后打开看板 | 「会显示权限错误态，不会崩溃。」 |
